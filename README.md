# GrantLens (지원금 렌즈)

> 소상공인·소기업이 받을 수 있는 정부·지자체 지원사업을 공고문 원문 근거와 함께 알려주는 개인 비영리 프로젝트

소개 페이지: https://civic-llm-lab.github.io/grantlens/

## 무엇을 하나요
지원사업 공고문은 길고, 신청자격은 본문·표·첨부파일에 흩어져 있습니다.
GrantLens는 공고문을 읽고 사업자 정보(지역, 업종, 업력, 매출, 상시근로자 수 등)와 대조해서 다음을 알려주는 것을 목표로 합니다.

- **신청 가능 / 불가 / 확인 필요** 판정
- 판정의 근거가 되는 **공고문 원문 구절**
- 대상이 아닌 경우 **어떤 조건 때문인지**

## 이용하는 공공데이터
| 데이터 | 제공 | 용도 |
|---|---|---|
| [지원사업정보 API](https://www.bizinfo.go.kr/apiDetail.do?id=bizinfoApi) | 기업마당 (중소벤처기업부) | 지원사업 공고 목록과 공고문 첨부파일 |
| [공공서비스(혜택) 정보](https://www.data.go.kr/data/15113968/openapi.do) | 행정안전부 (공공데이터포털) | 지원 서비스 정보 (예정) |

- 공고 정보는 출처(기관명, 원문 링크)를 함께 표시합니다.
- 수집 주기는 하루 몇 차례이며, 첨부파일 요청 사이에 간격을 두어 원 서버에 부담을 주지 않습니다.

## 운영 원칙
- **비영리**: 광고, 유료 기능, 컨설팅 연결이 없습니다.
- **참고용**: 판정 결과는 참고 정보입니다. 최종 자격은 반드시 공고문 원문과 주관기관을 통해 확인해야 합니다.
- **개인정보 최소화**: 판정에 필요한 사업자 속성만 사용하며 사업자등록번호 등 식별 정보는 받지 않습니다.
